Get started
  1. Open monkeytype.com (reload it if it was already open).
  2. Type a test to the end.
  3. Click Open dashboard below to see your stats.

Everything stays on this computer. TypeLens only listens to the typing box on monkeytype.com. The desktop app is optional: the dashboard works in the browser too.
